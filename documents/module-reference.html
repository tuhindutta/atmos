Web application

atmos.py FastAPI routes · SSE streaming · lifecycle

Creates the browser-facing API, initializes the runtime, adapts LangGraph events to server-sent events, and connects chat requests to SQLite history.

Data models

AgentRuntime

Runtime bundle holding the agent, SQLite memory, shell tools, and request lock.

agentmemoryshell_toolsrequest_lock
ChatRequest(BaseModel)

Validates chat input: thread_id (1–100 chars) and message (1–20,000 chars).

MemoryRequest(BaseModel)

Validates a memory body whose content is 1–5,000 characters.

Async generator that maps model/tool callbacks to UI event objects, tracks the answer, and retries failed execution up to the configured recovery count.

Persistent-shell modules

shell/persistent_shell.py PTY-backed interactive Bash process

Maintains one interactive Bash process so working directory, environment, and shell variables persist between commands.

Types

CommandResult(output, state, exit_code=None)

Immutable result for command, poll, or input operations. States are completed, waiting_for_input, and idle.

ShellSessionError(RuntimeError)

Base exception for persistent-shell session errors.

ShellSessionClosed(ShellSessionError)

Signals operations attempted after the shell session closes or exits.

PersistentShell(shell="bash", idle_timeout=1.0, encoding="utf-8")

Class that owns the interactive shell, its PTY, command markers, and output buffers.

PersistentShell methods

__init__(shell, idle_timeout, encoding)

Validates configuration and starts the shell session.

_start_session() -> None

Initializes session state and launches Bash on a pseudo-terminal.

reset() -> None

Terminates the current shell and starts a clean one.

run(command, timeout=None) -> CommandResult

Runs a command in the persistent shell and waits for completion or a quiet period.

send_input(text, *, newline=True, timeout=None) -> CommandResult

Sends input to the active command, optionally followed by Enter.

poll(timeout=None) -> CommandResult

Waits for additional output without sending input.

close(grace_period=1.0) -> None

Sends SIGHUP, waits briefly, force-kills if needed, and releases the PTY.

__enter__() / __exit__(...)

Supports context-manager use and closes the session on exit.

_validate_timeout(timeout)

Rejects negative quiet-period values.

_wait(timeout) -> CommandResult

Reads output until completion, a recognized prompt, or an idle timeout.

_looks_like_prompt() -> bool

Checks buffered output for common password/confirmation/input prompts.

_read_available(timeout) -> bool

Reads available PTY bytes without blocking beyond the requested interval.

_extract_completion() -> int | None

Detects the unique command completion marker and extracts the exit status.

_result(state, exit_code=None) -> CommandResult

Normalizes ANSI escapes, line endings, and terminal backspaces into output text.

_write(text) -> None

Writes encoded text fully to the PTY and reports closed-session errors.

_disable_echo() / _drain_startup() -> None

Configures the PTY to avoid echoed input and discards startup noise.

_reap_nonblocking() / _process_exited() -> bool

Checks and reaps the child process without waiting indefinitely.

_ensure_open() -> None

Raises ShellSessionClosed when an operation requires a closed session.
