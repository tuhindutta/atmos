Atmos · Architecture

Tools

The master agent receives tools assembled by create_master_agent(). Tool groups are created by focused factories and combined into one LangGraph agent toolset.

Master-agent tool registry

LangGraph master agent

Persistent shell

Manager starts/stops a local shell API; command tools call its HTTP endpoints.

start_persistent_terminal run_command poll_command send_command_input reset_shell stop_persistent_terminal

Shutdown cleanup stops the managed terminal.

Atmos resources

Discover and manage user-provided skill/agent definitions under .atmos.

list_atmos_resources read_atmos_resource create_atmos_resource

Reads are limited to supported skill and agent Markdown paths.

Memory

SQLite tools for durable facts and the active conversation's stored history.

remember_memory search_memories recent_messages_with_events_tool

History lookup uses the request's active thread ID.

Child agent

Delegates a focused query to a temporary agent with its own prompt.

query_sub_agent

The child gets shell and resource tools, then cleans up its terminal.

Progress reporting

Sends short user-facing updates through the agent event stream.

report_progress

Progress events are emitted as custom agent events and streamed to the client.

Tool results

Tool start, completion, and error events are represented in the streamed trace.

tool_start tool_end tool_error

Completed trace entries are stored with the assistant message.

Shell-tool call path

Agent chooses a tool For example, run_command or start_persistent_terminal.
→
Local tool wrapper Tool wrapper sends a JSON request to the selected loopback API endpoint.
→
Persistent shell API Executes or manages the persistent shell and returns structured output.

The shell manager tries the configured port and up to four successive ports. Command tools use the endpoint that successfully started.
